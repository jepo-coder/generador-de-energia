Sobre el proyecto

♻️

¿Qué es?

Una rueda de agua construida con materiales sencillos y reciclables, conectada mediante un eje a un motor DC y un LED.

🎯

¿Para qué?

Demostrar a pequeña escala cómo el movimiento del agua puede aprovecharse para producir una pequeña cantidad de energía eléctrica.

El problema

En la actualidad, la energía eléctrica es necesaria para muchas de las actividades que realizamos diariamente. Sin embargo, gran parte de la electricidad todavía depende de recursos que pueden causar impactos negativos en el ambiente. Por esta razón, es importante conocer otras formas de obtener energía y comprender cómo funcionan.

El proyecto busca demostrar cómo aprovechar el movimiento del agua para producir una pequeña cantidad de energía eléctrica.

Pregunta de investigación

¿Cómo se puede aprovechar el movimiento del agua para generar energía eléctrica mediante una rueda de agua conectada a un motor DC?

Hipótesis

Si el movimiento del agua hace girar una rueda conectada a un motor DC, entonces será posible generar una pequeña cantidad de energía eléctrica capaz de encender un LED, debido a la transformación de la energía hidráulica en energía mecánica y posteriormente en energía eléctrica.

Objetivos

Objetivo general

Demostrar cómo el movimiento del agua puede transformarse en energía eléctrica mediante la construcción de un generador de energía hidráulica a pequeña escala.

Comprender cómo se transforma la energía potencial del agua en energía cinética y posteriormente en energía eléctrica.

Construir una rueda de agua utilizando materiales sencillos y reciclables.

Física del proyecto

El agua colocada a cierta altura posee energía potencial gravitatoria. Al caer, esta se transforma en energía cinética. Luego, el agua ejerce fuerza sobre las paletas y hace girar la rueda.

Ep = mgh

Energía potencial gravitatoria.

Ec = ½mv²

Energía cinética.

m = masa del agua
g = aceleración de la gravedad
h = altura
v = velocidad

No toda la energía se convierte en electricidad

Hay pérdidas por fricción, resistencia del aire, resistencia interna del motor y agua que no golpea correctamente las paletas.

"""Generador de Energía Hidráulica: modelo educativo en condiciones ideales.

Cadena de energía: agua (Ep) -> rueda -> motor DC como generador -> LED.
Los valores son de simulación; no provienen de mediciones del prototipo.
"""
import argparse
from math import inf, sqrt

G = 9.8  # aceleración de la gravedad (m/s²)


class Agua:
    """Masa de agua situada a cierta altura."""

    def __init__(self, masa_kg: float, altura_m: float):
        if not (0 < masa_kg < inf and 0 < altura_m < inf):
            raise ValueError("La masa y la altura deben ser mayores que cero.")
        self.masa_kg = masa_kg
        self.altura_m = altura_m

    def energia_potencial(self) -> float:
        """Ep = m·g·h"""
        return self.masa_kg * G * self.altura_m

    def velocidad_ideal(self) -> float:
        """v = √(2·g·h), sin resistencia del aire."""
        return sqrt(2 * G * self.altura_m)

    def energia_cinetica(self) -> float:
        """Ec = ½·m·v²"""
        return 0.5 * self.masa_kg * self.velocidad_ideal() ** 2


class RuedaAgua:
    """Recibe la energía del agua. 'perdidas' agrupa fricción, calor y
    agua que no golpea bien las paletas (valor entre 0 y 0.95)."""

    def __init__(self, perdidas: float = 0.5):
        if not 0 <= perdidas <= 0.95:
            raise ValueError("Las pérdidas deben estar entre 0 y 0.95.")
        self.perdidas = perdidas

    def energia_mecanica(self, agua: Agua) -> float:
        return agua.energia_cinetica() * (1 - self.perdidas)


class MotorGenerador:
    """Motor DC funcionando como generador (modelo simplificado: las
    pérdidas ya se agrupan en la rueda)."""

    def energia_electrica(self, energia_mecanica: float) -> float:
        return energia_mecanica


class Led:
    """Registra la energía recibida. Cuánta necesita para encender depende
    del LED real; este modelo no lo calcula."""

    def __init__(self):
        self.energia_j = 0.0

    def recibir(self, energia_j: float) -> None:
        self.energia_j = energia_j

    @property
    def recibe_energia(self) -> bool:
        return self.energia_j > 0


class SistemaHidraulico:
    """Controlador: conecta agua, rueda, motor y LED."""

    def __init__(self, agua, rueda, motor=None, led=None):
        self.agua, self.rueda = agua, rueda
        self.motor = motor or MotorGenerador()
        self.led = led or Led()

    def simular(self) -> dict:
        electrica = self.motor.energia_electrica(self.rueda.energia_mecanica(self.agua))
        self.led.recibir(electrica)
        return {
            "energia_potencial_j": round(self.agua.energia_potencial(), 2),
            "velocidad_ms": round(self.agua.velocidad_ideal(), 2),
            "energia_cinetica_j": round(self.agua.energia_cinetica(), 2),
            "energia_util_j": round(electrica, 2),
            "led_recibe_energia": self.led.recibe_energia,
        }


def informe(r: dict) -> str:
    led = "recibe energía" if r["led_recibe_energia"] else "sin energía"
    return (
        f"Energía potencial : {r['energia_potencial_j']:.2f} J\n"
        f"Velocidad ideal   : {r['velocidad_ms']:.2f} m/s\n"
        f"Energía cinética  : {r['energia_cinetica_j']:.2f} J\n"
        f"Energía útil      : {r['energia_util_j']:.2f} J\n"
        f"LED               : {led}"
    )


if __name__ == "__main__":
    p = argparse.ArgumentParser(description="Simulación del generador hidráulico")
    p.add_argument("--altura", type=float, default=1, help="altura de caída (m)")
    p.add_argument("--masa", type=float, default=0.5, help="masa de agua (kg)")
    p.add_argument("--perdidas", type=float, default=50, help="pérdidas (%%)")
    a = p.parse_args()
    sistema = SistemaHidraulico(Agua(a.masa, a.altura), RuedaAgua(a.perdidas / 100))
    print(informe(sistema.simular()))

¿Por qué se enciende el LED?

  
Al girar la rueda, el eje mueve el motor DC. En esta situación, el motor puede actuar como generador y producir una diferencia de potencial. La corriente resultante llega al LED y produce luz.

¿Realmente existe la energía gratis?

  

    
Mito
La expresión “energía gratis” no significa que la energía aparezca de la nada. La fuente inicial es el agua que se mueve o que fue colocada a cierta altura.

    
Realidad
Si se utiliza una bomba para subir nuevamente el agua, esta consume electricidad. Además, existen pérdidas por fricción y calor.

  

  
Es más correcto considerar el proyecto como un sistema demostrativo de transformación de energía hidráulica en energía eléctrica.







  
Energía hidráulica en Guatemala

  

    

      
Guatemala posee 38 cuencas hidrográficas con posibilidad de aprovechamiento energético:

      
  • 18 en la región del Pacífico
  • 10 en la región del Atlántico
  • 10 en la región de Occidente-Norte

      
Las hidroeléctricas funcionan bajo un principio similar al prototipo, pero a una escala mucho mayor. Un ejemplo es la Central Hidroeléctrica Chixoy.

    

    
    
  







  
Ventajas y limitaciones

  

    
Ventajas
  • Es una fuente renovable.
  • Aprovecha el ciclo natural del agua.
  • No requiere quemar combustibles fósiles directamente para producir electricidad.
  • Puede utilizarse en instalaciones grandes o pequeñas.
  • Permite estudiar de manera práctica la transformación de energía.

    
Limitaciones
  • Las hidroeléctricas pueden modificar los ríos y afectar ecosistemas.
  • Dependen del caudal y disponibilidad de agua.
  • El prototipo produce una cantidad pequeña de electricidad.
  • Existen pérdidas de energía.
  • La eficiencia depende del diseño de la rueda y otros componentes.

  







  
Observaciones

  

    
Durante la realización del proyecto observamos que el movimiento de la rueda depende de la cantidad de agua que cae sobre las paletas y de la forma en que esta las golpea.

    
La posición de las paletas y la fricción del eje pueden afectar el movimiento de la rueda.

El motor funcionó como un pequeño generador y produjo una diferencia de potencial que permitió encender el LED.

Los resultados coinciden con la investigación realizada. La energía no aparece de la nada: se transforma.

  
Agua↓Movimiento↓Rueda↓Motor DC↓Electricidad↓LED
